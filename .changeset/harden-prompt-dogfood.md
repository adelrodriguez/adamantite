`adamantite harden` asks the agent to explore the project's documentation before it lists the standards, and to report the files that no instruction points to. Each written standard goes on to the enforcement check, also when the code breaks it. Each candidate comes with its scope, a case that the rule must report, and a case that it must accept. The agent scores the candidates, shows only the strong ones, and lists the decisions for the maintainer apart from the candidates.
