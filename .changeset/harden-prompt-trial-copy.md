The `adamantite harden` prompt now tells the agent to try a rule in a trial copy of the project, with a case that the rule must report and a case that it must accept, so a rule with options or from a JS plugin gives real evidence. A candidate that needs a choice from the maintainer goes to the Decisions list instead. Each rule says what it guarantees and what it does not, and a construct that the code never uses needs a written source before it becomes a standard.
