Write `oxlint.config.ts` as a managed file, and install the managed packages in `Setup`

`adamantite init` and `adamantite update` now write `oxlint.config.ts` only whole, and only when the file does not exist or still holds what Adamantite wrote, by its hash in `.adamantite/adamantite-lock.json`. The config lists its imports in the order that Oxfmt sorts them, and wraps `extends` when it passes 100 characters, so `adamantite fix` leaves it unchanged. A config that an earlier version wrote and nobody changed is replaced with the current version. A config that you changed is kept, and `adamantite doctor` reports a lint preset that the lockfile selects and no Oxlint config of the project applies with the new `missing-lint-preset` finding. A preset counts as applied in `extends`, in an `overrides` entry that spreads its `rules`, as the jest and vitest presets show, and in the Oxlint config of a workspace package. Doctor also requires the plugin package of a preset that only a workspace package config applies. It still reports a preset before core, two presets that report the same defects, a config that Oxlint cannot load, and missing type-aware options. When the setup no longer runs `check` or `fix`, `update` deletes the config if nobody changed it. A project with a conflicting `.oxlintrc.json` gets no `oxlint.config.ts`, because Oxlint loads no config when it finds both, and Doctor reports the `conflicting-oxlint-config` finding. Doctor also reports a JSON config beside `oxlint.config.ts` with that finding, which replaces `shadowed-legacy-oxlint-config`.

`init` and `update` now install Oxlint, tsrs, Oxfmt, Knip, Sherif, and the managed plugin of each selected preset from the recorded selection, and only the packages that `package.json` does not declare at the managed version. `update` prints the packages it installed under "Packages installed". A package that a pnpm catalog declares stays as it is, and Doctor reports an outdated catalog entry. `update` no longer updates a tool that the recorded setup does not select.
